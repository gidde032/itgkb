## Summary

The highest-value account advice is boring and effective: use a password manager, make each
password long and unique, and never reuse one across sites. Reuse is what turns one leaked site
into a dozen compromised accounts, so a manager plus MFA covers most real risk.

## Guidance

1. **Use a password manager.** It generates and stores long random passwords so the user only
   remembers one strong master password. This removes the reason people reuse passwords.
2. **Length beats complexity.** A long passphrase of a few unrelated words is both stronger and
   easier to type than a short string of symbols.
3. **Unique per site.** Reuse is the real danger; a manager makes uniqueness free.
4. **Pair with MFA.** Even a strong password can be phished — a second factor is what stops the
   attacker who has the password (see MFA enrollment).

## Resolution Steps

1. Help the user pick and set up a reputable password manager, import or reset existing logins to
   generated passwords, and secure the master password with MFA.
2. Prioritize changing reused passwords on important accounts (email first — it's the reset path
   for everything else).

## Notes / Edge Cases

- Forced periodic password changes tend to produce weaker, patterned passwords; modern guidance is
  to change only on suspicion of compromise plus strong length and MFA.
- Browser-saved passwords are better than reuse but weaker than a real manager (tie them to a
  device/account lock at minimum).
